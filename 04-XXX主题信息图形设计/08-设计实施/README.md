# 08｜设计实施

把已确认的叙事结构和视觉编码落地为可交付的信息图形。

建议流程：低保真草图 → 内容网格与版面 → 统计图 / 图标 / 文字 / 图片整合 → 初稿 → 核对事实、视觉比例与版权 → 迭代 → 最终导出。

子目录：
- `01-草图与版式/`：手绘草图、版面方案、网格和结构图。
- `02-可编辑源文件/`：Figma、AI、SVG、PPT 等可继续编辑的文件。
- `03-设计迭代版本/`：阶段性版本与修改记录。
- `04-最终交付/`：确定版图片/PDF/SVG/展示图，附项目说明。

**发布前校验**：
- [ ] 成品每一处数值、比例、地名、图片对应真实来源；
- [ ] 视觉形式与第 2 阶段标签决策一致，若有变更已说明；
- [ ] 有完整的标题、来源、计量单位、必要图例和注释；
- [ ] 文字在目标阅读尺寸下清晰；
- [ ] 源文件可编辑、最终导出正确、文件版本可追溯。

填写 [设计版本与交付记录.md](设计版本与交付记录.md)。
