# 05｜叙事框架搭建：用若干独立字段组成可阅读的信息单元

这一步**不等于第 4 阶段基础数据表建模**：先保持“每列一个字段”，再选择几列之间的关系，让它们服务一个明确的故事问题。

示例（只说明字段搭配，非本主题真实资料）：
- **名称 + GPS**：知道“某个对象在哪里”；在地图上显示地点及说明。技术上 GPS 可能是 `lat` + `lon` 两个独立列。
- **地区名称 + GDP 数值**：知道“某地 GDP 是多少”；如果要比较，还需要统一年份、单位、价格口径。
- **地区 + 年份 + GDP**：比较地区跨年份变化，可借用折线或分组柱形图。
- **人物 + 事件 + 顺序编号**：构建阅读顺序；只有当顺序承载核心意义时才可能归为编年逻辑。
- **上级类别 + 下级类别 + 数值**：构建可比的层级组成信息，可借用 Treemap 等图形。

**叙事与选图步骤**：
1. 提出一个读者能回答的明确问题；
2. 选择关键字段、关联键、统计口径；必要时做分组和计算；
3. 规定一个叙事单元对应的图表/图标/文字/照片模块；
4. 规划入口 → 核心事实 → 对比/解释 → 结论 → 数据来源；
5. 检查单位、因果性和解释力度；不要用“好看的布局”替代数据关系。
