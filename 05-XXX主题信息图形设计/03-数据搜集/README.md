# 03｜数据搜集

按来源分开保管：
- `01-公共数据集/`：政府公开数据、机构公开数据、开源数据集等；保留原始格式及许可证/使用条件。
- `02-文本文献/`：论文、报告、网页、采访文稿、说明书等；保留引用信息和摘录位置。
- `03-自建数据集/`：自主调查、观察、拍摄、编码、测量记录；说明采集方法、样本量和局限。

**不要把不同来源直接拼在一起**：先登记出处、口径和许可，再在第 4 阶段规范化。

请在 [数据来源登记.md](数据来源登记.md) 为每一项资料编号，明确：题名、链接、作者/机构、获取日期、数据时间范围、许可、指标定义、可信度与待核对问题。资料不足时不要编造数值。
