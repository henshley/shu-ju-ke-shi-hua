# 02｜主题内容分析（与大模型共同讨论）

本阶段决定“**表达何种数据关系**”与“**采用哪些表现标签**”，两者是不同层次；必须保存沟通记录和选择依据。

建议按以下顺序讨论：
1. **主导数据架构**：五大逻辑（编年、层级、编目、字母表、地理图形）中哪一个最符合主题的数据组织？是否存在附属逻辑？
2. **信息图形类型**：从 02 已有的 17 种常用类型中选择主/辅标签，如文字型/列表型、词云图、图片式等；用作品的核心表达目的和阅读逻辑证明，不按“有照片”或“有时间”草率推断。
3. **视觉风格**：平面矢量、照片、线描、拼贴、插画、极简等；风格可以交叉搭配，不应直接替代类型判断。
4. **技术/编码方法**：选用哪些统计图、ISOTYPE 符号、地图、矩阵等；参考 [03-统计图形分析](../../03-统计图形分析/)。
5. **决策输出**：最终保留哪些标签，弃用什么方案，各自理由及待核实事项。

模板：[主题定位与标签决策.md](主题定位与标签决策.md)。将与大模型讨论的记录保存至 `大模型讨论记录/`；具体对照素材放至 `类型与风格参考/`。
