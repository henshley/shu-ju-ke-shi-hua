# 03｜跨原则对照实验

比较两种或多种视觉线索同时存在时，哪一种更容易控制分组、注意和阅读顺序。此处是**实验与操作记录区，不是已经得出的研究结果**。

推荐试验任务：
- 接近 vs 相似：固定颜色，调整距离；固定距离，调整颜色。
- 接近 vs 同域：固定元素位置，添加或删除共享区域边界。
- 同步 vs 共同命运：保持运动方向，改同步时刻；固定时刻，改变运动方向。
- 连续 vs 连接：用平滑路径与显式连边对照。
- 简单 vs 视觉焦点：减少无效装饰并评估重点识别率。

每次记录：**研究问题、对照变量、未变条件、素材、观看者、任务、可量化结果、主观反馈、失败和局限**。禁止用预期效果冒充观察结果。
