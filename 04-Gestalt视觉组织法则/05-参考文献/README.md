# 05｜理论参考与设计来源

优先区分研究论文、知觉理论概述和面向设计的解释文章；概念文档不冒称所有扩展项都是“经典定律”。

| 来源 | 研究内容 | 类型 |
|---|---|---|
| [Wagemans 等（2012）](https://doi.org/10.1037/a0029333) | 知觉分组与图底组织 | 学术综述 |
| [Palmer（1992）](https://doi.org/10.1016/0010-0285(92)90014-S) | 共同区域 | 研究论文 |
| [Palmer & Rock（1994）](https://doi.org/10.3758/BF03200760) | 统一连接与知觉组织 | 研究论文 |
| [Interaction Design Foundation](https://ixdf.org/literature/topics/gestalt-principles) | 面向设计的 Gestalt 应用 | 设计教学 |
| [Nielsen Norman Group](https://www.nngroup.com/topic/gestalt/) | 视觉设计和可用性中的组织线索 | 设计实践 |

额外研究：同构原则的理论本义及“异质同构”设计概念应分别寻找原始文献；视觉焦点、涌现、多稳态、恒常性另标记为知觉现象/设计扩展，不以 Gestalt 分组规律同等对待。
