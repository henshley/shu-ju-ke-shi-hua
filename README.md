# 信息图形与数据可视化

本仓库是《信息图表与数据可视化》课程项目。第一版以本次提供的《信息图表与数据可视化-3(1).pptx》为材料，第 3 章提供类型和案例，第 4、5 章提供设计与阅读方法。文档中的统计方法分为课件原图可辨认的做法和同类数据可以采用的做法。

## 01 信息图形数据逻辑

先判断哪些关系让信息成为一个整体，再决定用什么图形表达。对同一张图，也可以分别判断它的整体结构和局部结构。

| 数据逻辑 | 判断时问什么 | 概念文档 |
| --- | --- | --- |
| 编年型 | 互换节点位置后，事件的先后关系会不会被改写？ | [编年型](01-信息图形数据逻辑/01-编年型信息图形概念定义.md) |
| 层级型 | 任取一个下层节点，能沿着关系找到它的上级或来源吗？ | [层级型](01-信息图形数据逻辑/02-层级型信息图形概念定义.md) |
| 编目型 | 每个条目按什么共同规则归组、比较或查阅？ | [编目型](01-信息图形数据逻辑/03-编目型信息图形概念定义.md) |
| 字母表型 | 字母、字符或约定符号怎样定位具体条目？ | [字母表型](01-信息图形数据逻辑/04-字母表型信息图形概念定义.md) |

## 新案例补充方法

1. 将案例图放入 [02 下对应的案例子文件夹](02-信息图形类型案例/README.md)，图片和说明文档使用同一案例编号。在分析中注明课件页码或原图出处，记录可见的标题、署名及图例。
2. 用一句话写出图回答的问题，随后记录最小数据单位、主要关系、统计口径、视觉编码、阅读顺序。把原图可见的信息与设计推断分别表述，缺失的分母、单位或来源留待核对。
3. 选择对应概念文档，新增指向单例说明文档的相对链接。出现反例或新的表达方法时，在同次提交中更新相关的判断条件、适用范围或设计原则，并用案例说明改动依据。
4. 出图前依次检查数据和字段、结构与排序、编码与版式、关联与结论。检查读者是否能识别主题、读出参数、定位重点，并分清数据事实与作者解读。依据课件第 40、42–43、54–55、69–71 页。
