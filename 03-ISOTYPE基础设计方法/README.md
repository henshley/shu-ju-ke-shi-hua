# 03｜ISOTYPE 基础设计方法

> **ISOTYPE 是跨越不同信息图形类型的视觉符号语言与信息转译方法，不是五大数据逻辑之一，也不是 02 的第 18 种信息图形。** 本目录把历史背景、图符语言、数量编码、图表组织、案例研究和设计实践拆开研究。

## 一、ISOTYPE 是什么

ISOTYPE（International System of Typographic Picture Education，国际图画文字教育体系）源自 20 世纪 20 年代维也纳的图画统计实践。它不是简单地把人物小图标排成行，而是一套把事实、统计数据和社会信息转译成可阅读图画语言的方法：先理解和选择信息，再确定符号、数量单位、组合方式、标题、文字、色彩和阅读结构。

**最重要的数量表达原则：** 当图形符号承担数量编码时，数量增加应优先增加相同尺寸、相同含义的符号个数，而不是把一个符号任意放大。每个符号代表的数量必须说明。

## 三、ISOTYPE 的方法框架

1. **信息理解与筛选**：明确主题、受众、问题、统计口径和重要事实。
2. **信息转译（Transformation）**：把数据表和专家语言重组为适合公众理解的图画陈述。
3. **图符设计**：为对象或概念选择可识别、语义稳定的图形符号。
4. **数量编码**：确定一个符号代表多少，重复符号表达数量，必要时说明分数或近似值。
5. **图表组织**：通过行列、轴线、分组、地图位置、流向等形成比较关系。
6. **视觉叙事**：使用标题、说明、图例、色彩和辅助图像建立阅读入口与信息层级。
7. **核查与修订**：核对原始数据、符号单位、舍入、图形比例、来源和潜在误导。

这是一套用于现代设计实践的工作框架，不代表历史 ISOTYPE 存在一份固定、适用于所有情境的机械步骤表。

## 四、与本仓库其他目录的关系

- **01 信息图形数据逻辑**：判断信息整体由什么数据关系组织。
- **02 信息图形类型案例**：判断作品采用哪一种表现类型。
- **03 ISOTYPE（本目录）**：判断是否采用图画符号、重复单位和信息转译方法。
- **04 统计图形分析**：选择统计图、字段映射和计算方式。
- **05 Gestalt 视觉组织法则**：分析视觉元素如何被分组、识别和组织。
- **06 主题信息图形设计**：将前述方法用于一个具体选题。

同一张作品可以同时属于某一种信息图形类型、采用某一种数据逻辑、使用 ISOTYPE 符号，并运用 Gestalt 组织线索。它们是不同分析维度，不互相替代。

## 五、学习与案例记录约定

- 历史事实、原作特征、学术研究结论、现代设计建议分别标明。
- 不把所有图标插画都称为 ISOTYPE；要检查符号语义、标准化、数量单位和信息转译是否构成系统。
- 不把“每个符号固定代表一个数值”误解为“所有 ISOTYPE 图表都只能使用人物图标或只能表达数量”。
- 不把历史作品的简化、舍入或视觉强调直接当作现代数据图的准确性标准。
- 案例图片优先链接有出处的馆藏或项目页面；未经授权不复制受版权保护的图像。
- 每个案例都要区分原始数据、设计选择、视觉效果和作者的叙事立场。
