# 05｜ISOTYPE 设计实践

本部分把前面的理论转化为可以执行的设计流程、质量检查和案例分析方法。它不是把历史规则机械套用到所有项目，而是提供一套可以根据数据和受众调整的工作框架。

| 文档 | 用途 |
|---|---|
| [01-从原始数据到图画统计图](./01-从原始数据到图画统计图.md) | 设计工作流程 |
| [02-ISOTYPE 设计检查清单](./02-ISOTYPE设计检查清单.md) | 图符、单位、排列、文字、色彩和数据核查 |
| [03-案例分析模板](./03-案例分析模板.md) | 收集和分析新案例 |
| [04-数据准确性与视觉叙事伦理](./04-数据准确性与视觉叙事伦理.md) | 舍入、删减、强调和潜在误导审查 |

## 建议工作方式

先用真实数据做一张不带装饰的基础结构草图，再确定图符和数量单位，最后加入色彩、标题、注释和视觉叙事。每次迭代都保留原始数据和修改记录。
