# ISOTYPE 设计检查清单

## A. 信息与数据

- [ ] 主题问题和目标受众明确。
- [ ] 原始数据有可追溯来源。
- [ ] 统计对象、单位、时间范围和口径明确。
- [ ] 数据筛选、删除、聚合和舍入均有记录。
- [ ] 不把估算值或近似值写成精确值。

## B. 图符语言

- [ ] 图符能代表实际统计对象或概念。
- [ ] 同一含义使用稳定符号。
- [ ] 图符经过适当简化，缩小后仍可识别。
- [ ] 需要区分的类别有明确的限定符号。
- [ ] 数量图符与主题辅助图像能够区分。

## C. 数量编码

- [ ] 一个图符代表的数量写清楚。
- [ ] 同一比较范围内图符尺寸一致。
- [ ] 数量差异通过图符个数表达，而不是随意放大图符。
- [ ] 图符数量可以由数据表复算。
- [ ] 余数、分数、取整和误差已说明。

## D. 排列与叙事

- [ ] 行列、地图、轴线或流向具有明确含义。
- [ ] 可比对象使用相同统计口径和单位。
- [ ] 阅读顺序和标题能够帮助读者找到重点。
- [ ] 颜色、形状、填充和位置的含义不冲突。
- [ ] 图例、单位、来源和注释完整。

## E. 可读性与伦理

- [ ] 在目标尺寸和观看距离下可读。
- [ ] 黑白打印或色觉差异情况下仍能辨别关键类别。
- [ ] 未通过删减、移动或增添图符扭曲数据。
- [ ] 视觉强调没有掩盖重要背景或不确定性。
- [ ] 设计者已检查作品可能造成的错误推断。

## 最终读者测试

请没有参与设计的人回答：
1. 这张图主要讲什么？
2. 一个图符代表多少？
3. 两个指定类别谁更大，差多少？
4. 颜色和不同形状分别代表什么？
5. 哪些数值是精确值，哪些经过近似处理？

若读者无法回答，应先修正图例、单位、符号和排列。
