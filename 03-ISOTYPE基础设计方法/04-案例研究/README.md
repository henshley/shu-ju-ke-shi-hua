## 案例分析要求

1. 优先使用 Isotype Revisited、学术论文或馆藏档案中可核实的作品信息。
2. 不将案例说明中的作者评价直接当作客观事实；明确区分原始图表信息与研究者解释。
3. 案例图片由原项目或馆藏页面提供时，优先链接原页面；未经许可不将图像复制到仓库。
4. 每个案例必须说明图符单位、图例和统计口径；无法从资料核实的内容标记“未核实”。
5. 对历史作品中的舍入、删减和叙事倾向进行批判性分析，不把历史方法浪漫化。
