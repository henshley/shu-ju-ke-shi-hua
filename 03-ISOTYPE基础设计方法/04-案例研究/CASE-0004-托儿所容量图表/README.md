# CASE-0004｜托儿所容量图表（Izostat Institute）

## 1. 案例背景

1931 年，Otto Neurath 与同事前往莫斯科，协助建立苏联图画统计机构 Izostat Institute，并培训当地艺术家和技术人员。Isotype Revisited 对 1932 年的城市托儿所容量图表和 1934 年的 “Crèches” 图表进行了比较。

## 2. 设计差异

- 1932 年图表中的“婴儿”图符与所表达的托儿所容量不完全匹配，图形保留了较多自然主义面部和头发细节。
- 图表上方的托儿所场景属于 guide-picture，可帮助读者理解主题或划分内容；但场景中的人物和布置也可能带有理想化的宣传意味。
- 1934 年 “Crèches” 图表简化了婴儿图符，删除了不必要的细节，并用红色和绿色区分城市与农村类别。
- 后一图表的引导图像去掉了人物，强调展示对象是托儿所而不只是儿童。

## 3. 设计分析

### A. 图符适切性
图符应代表统计对象本身。若图表表达的是“托儿所名额”，婴儿图符可能让读者误以为统计的是儿童人数；托儿所或婴儿床等图符可能更贴近统计对象。

### B. 简化与识别
去掉不必要的面部和头发细节，可以使图符更适合重复和小尺寸阅读，但仍应保持对象可辨认。

### C. 色彩编码
红色与绿色在该图表中区分城市和农村，不应把这组颜色解释成所有 ISOTYPE 项目都必须遵守的固定色彩含义。

### D. 引导图像与数量图符
引导图像交代情境，不承担图符单位。设计时应避免让读者把背景场景中的人物也计入统计数量。

## 4. 可复用方法

- 先确认统计对象，再决定图符，不要只选择“看起来相关”的图像。
- 区分计数图符和主题引导图像。
- 颜色含义要在当前项目内定义清楚。
- 简化图符时保留识别所需的关键特征。
