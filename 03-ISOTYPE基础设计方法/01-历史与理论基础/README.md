## 本部分要形成的认识

ISOTYPE 不是由某一位设计师独立发明的一套图标风格。它依靠统计、社会科学、教育、图形设计和制作人员协作，逐步形成。历史语境解释了为什么它强调清晰、可比较、可复制和面向公众的图画表达。
