# 03｜数量表达与图表结构

本部分研究如何把数值转化为可计数的图符单位，以及如何通过排列、坐标、地图、密度和流向形成信息结构。

| [03-图符排列、比较与趋势](./03-图符排列比较与趋势.md) | 行列、分组、轴线、顺序与跨图比较 |

## 基本提醒

ISOTYPE 不等于所有统计图都必须用重复小图标。它可以把图符作为数量单位，也可以把图符放入地图、流向或其他图表结构中。要先明确图符在图表中承担的是数量、类别、位置、方向还是主题说明。
