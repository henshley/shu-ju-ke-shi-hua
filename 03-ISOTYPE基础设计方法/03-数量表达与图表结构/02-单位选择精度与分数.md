# 单位选择、精度与分数

## 1. 为什么要选择单位

单位决定图表中需要重复多少个图符，也影响版面密度和读者能否看出差异。单位过小，图符太多，图表拥挤；单位过大，图符减少，但不同数值可能被舍入成相同数量，细节消失。

历史 ISOTYPE 实践会在信息清晰度、图符数量和数据差异之间权衡。现代设计应在保留这种设计问题的同时，把数据准确性作为不可随意牺牲的约束。

## 2. 单位选择步骤

1. 找出数据的最小值、最大值和关键差异。
2. 估算若每符号代表 1、10、100、1000 等单位时需要多少图符。
3. 检查版面是否容纳、符号是否能数清。
4. 检查选择该单位后，重要差异是否仍能看出来。
5. 记录舍入和余数，必要时增加数字标签或采用更小单位。

单位不应只为了减少图标数量而选择；它应同时满足可读性与准确性。

## 3. 分数符号

当数据不能被固定单位整除时，可以考虑：
- 选择更小的单位；
- 使用有明确比例规则的部分图符；
- 用文字或数字标出余数；
- 在图例中说明近似值和舍入规则。

若使用半个图符、四分之一图符等部分符号，必须保证部分面积或形态与所表示的分数关系明确，并让读者能理解。不要随意切掉图符的一部分，却没有说明这代表什么。

## 4. 舍入与精度

历史案例研究显示，单位增大和视觉构图可能导致较明显的舍入；有时设计者甚至调整了图符数量以突出信息。这些案例可帮助理解转译过程，但不能作为现代统计图随意更改数据的许可。

现代设计至少应：
- 保留原始数值；
- 说明显示单位；
- 标注近似值或舍入方法；
- 在必要时附原始精确数字；
- 不将舍入后的图符数写成精确统计结果；
- 对可能改变结论的舍入做敏感性检查。
