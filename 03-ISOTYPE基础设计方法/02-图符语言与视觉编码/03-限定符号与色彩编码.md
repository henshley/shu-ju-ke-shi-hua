# 限定符号与色彩编码

## 1. 限定符号的作用

当同一类对象需要进一步区分时，可以在基本图符上加入有限的限定特征。例如，同一个人物基本形态可通过服饰、姿态或随身物件区分职业、身份或状态。限定特征应有明确含义，不能只是装饰。

## 2. 色彩承担什么信息

色彩可用于区分类别、状态、来源、流向或对比组。历史图表中曾使用颜色区分农业、工业、不同人群或贸易类别，但具体颜色语义随项目和时代而定，不能把某个颜色的含义当作全球固定规则。

## 3. 色彩编码的操作要求

1. 先定义颜色对应的类别或状态，再建立色彩表。
2. 同一类别在同一项目的各张图表中尽量保持同色。
3. 需要比较的组应使用可区分且视觉重量相近的颜色。
4. 不要同时用颜色和符号大小表达不同含义而未提供图例。
5. 考虑色觉差异、灰度打印和低质量屏幕；重要类别不能只靠颜色区分。
6. 标题、图例和说明应明确颜色对应的对象。

## 4. 实色、空心和不同形态

除色相外，还可以使用填充/空心、轮廓、纹理或限定符号区分类别。例如历史橡胶贸易图表用不同颜色和实心/空心符号区分生产、出口、进口和回收利用。使用多个视觉变量时，应让每个变量的意义可被解释。

## 5. 检查表

- [ ] 每种颜色是否有明确含义？
- [ ] 同一颜色是否在不同图表中保持一致？
- [ ] 图例是否与实际符号一一对应？
- [ ] 黑白状态下是否仍能区分关键类别？
- [ ] 色彩是否造成某个类别被不合理地强调？
