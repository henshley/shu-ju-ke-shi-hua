# 02｜图符语言与视觉编码

本部分研究如何把对象和抽象概念转化为可识别、可重复、语义稳定的视觉符号，并将符号、色彩、文字和辅助图像组合成系统。

| 文档 | 研究内容 |

| [01-图符语义与选择](./01-图符语义与选择.md) | 对象识别、概念映射、具象图符与抽象符号 |
| [02-图符简化、标准化与一致性](./02-图符简化标准化与一致性.md) | 轮廓提炼、风格统一、可复制性、符号复用 |
| [03-限定符号与色彩编码](./03-限定符号与色彩编码.md) | 类别、状态、限定信息和色彩语义 |

## 设计判断

不要先画一套漂亮图标，再勉强寻找数据含义。应先明确对象、类别和信息任务，再决定图符是否需要具象、抽象、组合或文字辅助。
