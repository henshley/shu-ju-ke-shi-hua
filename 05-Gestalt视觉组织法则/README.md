## 研究与更新原则

每增加真实案例，要区分：①图面上能看到的现象、②分析者的理论推断、③真实用户测试结果；不能用假想教学示例冒充真实案例。说明设计变量（距离、色彩、边界、线条、动画等）如何变化，并观察其效果。案例的图像与分析保存在 02-案例库，规则文档只链接索引。
