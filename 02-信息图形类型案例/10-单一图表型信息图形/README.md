# 单一图表型信息图形

课件第 31 页，Single chart。

把一个主要比较或分布关系交给核心图形表达。第 31 页用建筑或火箭剪影作为主体，标题、说明与局部小图服务于主问题。

## 制作与复核

先确定主图需要比较的字段与单位。若使用具象剪影编码数量，基线、长高比例和分组比例需要一致或有明确说明。
