# 图片式信息图形

课件第 29 页，Photo-graphic Infographics。

让照片承担对象识别、情境或叙事，再把数值、标记和文字叠加到可读的位置。第 29 页展示了图表内嵌照片和整版照片分区两种做法。

## 制作与复核

照片结合统计图时保留共同基线和数字，作为背景时用留白、色罩或独立标注区维持文本对比度。
