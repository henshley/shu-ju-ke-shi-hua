# 案例1｜Garin Fajar 视觉简历信息图形

![案例1图片｜Garin Fajar视觉简历](./案例1图片.webp)

> **常用信息图形种类**：13-视觉简历型信息图形（Visual Resume Infographic）  
> **五大数据架构逻辑**：**编目型为主**（同一人物 → 多个信息类别 → 各类别的具体条目），局部技能列表呈现独立、并列单元。  
> **主要统计表现**：技能点阵评分（Dot Rating）和语言能力百分比直接标注。  
> **图像信息**：原图未给出外部出处、评分定义、数值测量口径；以下不将装饰圆点误认为统计量。

## 基本分类

- **为什么是视觉简历型？** 全图围绕一名人物，组合姓名、肖像、自我介绍、教育、实习、联系方式、专业能力、软件和语言能力；用图标、色块、文字和局部统计符号表达个人档案。
- **为何主数据逻辑是编目型？** 不同模块归属于同一人物，但模块字段的性质并不统一：学历、实习、地址、能力项目及技能评分属于异构资料，构成“主体—类别—条目”的分类目录。
- **与字母表型的关系**：软件技能等子模块可作为“每项同一评分结构”的独立同构单元，可调换顺序；这只是**局部字母表型特征**。不能因为各模块可交换，就把全部异构信息理解为独立同构记录。
- **与编年型的区别**：经历条目出现2020年等年份，但页面不是以连续、单向、不可逆的时间序列组织全部内容。

## A｜基本的数据逻辑

**基本规则：一个主体 → 多类信息 → 分类条目／属性详情。**

| 核心特性 | 图中表现 | 结构含义 |
| --- | --- | --- |
| 单一主对象 | 人物肖像、竖排姓名“GARIN FAJAR” | 所有模块属于同一人物 |
| 主题分组 | Education、Experience、Abilities、Skills 等 | 异质字段分门别类 |
| 模块可跳读 | 教育、联系方式、能力区域互不依赖 | 阅读没有全局强制顺序 |
| 局部嵌套 | 实习名称＋说明＋年份；学校名称＋专业 | 一类资料包含多个条目属性 |
| 局部同构 | 软件 Logo＋重复七点评分位置 | 相同子字段支持并列比较 |
| 局部量化 | Bahasa 100%、English 40% | 仅部分信息具有数值 |

**抽象数据规律**：主体唯一、属性异构、按类归档、模块可重排、局部独立同构、少量等级／百分比指标。

## B｜统计图形、统计方式与计算方式

| 图形位置 | 图形形式 | 统计意义与处理方式 |
| --- | --- | --- |
| 右下软件技能 | **点阵评分图（Dot Rating）** | 每项软件后有七个圆点位置。点的重复与颜色用于展示等级差异，但缺乏明确图例，不能仅凭颜色推出真实评分 |
| 右下语言 | **百分比数值标注** | 直接写出 Bahasa 100%、English 40%；圆形底不是按比例分割的饼图或环形图 |
| 左下能力 | **分类图标列表** | Quality Control、Drafter、Interior Design 三种职业能力；符号主要起索引作用，无数量统计 |
| 左侧教育与经历、右侧联系信息 | **图文分类列表** | 分类整理、项目与字段匹配；年份只是履历的附属字段 |

- **统计处理**：若有明确评分标准，可采用离散等级计数及统一分母的比例换算。例如定义有效点数为 `k`、总点评分为 `n`，则 `占比 = k ÷ n × 100%`。**但本图未说明橙色和深色圆点的评分方向，不能擅自据此计算具体技能百分比。**
- **RAWGraphs 图形对应**：可借用 **Matrix plot（矩阵图）** 的行列布局，将“软件 × 评分位置”组织为规则点阵，再定制圆点、颜色及 Logo。此为**近似绘制方法**，不是声称原图直接由 RAWGraphs 生成。
- **数据与装饰区分**：上、下的橙色波点与大面积背景并无数值对应关系；语言数字的圆形外轮廓也不表达占比面积。

## C｜视觉编码

| 视觉编码 | 原图如何使用 | 效果与限制 |
| --- | --- | --- |
| **点** | 技能栏圆点、上角与下边装饰波点 | 技能圆点表达离散评价，其他波点纯装饰 |
| **线** | 白色人物描边、标题空心轮廓、橙色虚线、圆环 | 区分层次、分隔区域、强调人物与标题，非趋势线 |
| **面** | 酒红底块、奶油底、橙色技能区域及大圆底形 | 模块化信息分区、建立主次，不编码数值面积 |
| **体** | 肖像后方错位的玫红、橙黄剪影 | 制造伪立体纵深，不承担第三维数据 |
| **符号** | 学校、日历、地址、电话、邮件、人物、职业、软件 Logo | 替代或辅助文字，建立识别索引 |
| **色彩** | 酒红／玫红＋橙黄＋奶油色 | 醒目对比与视觉统一；无全局定量色标 |
| **字体** | 竖排姓名、大号“hi there”、斜粗体、空心实心标题叠加 | 标题层级化、文字图形化、强化活力 |
| **版式** | 左上照片、右上简介、中下分栏、右下橙色技能面板 | 人物为第一焦点，技能为第二焦点 |
| **图像** | 黑白裁切肖像、白色描边、后方彩色投影 | 快速建立人物身份和视觉冲击 |

**可迁移设计原则**：照片主视觉＋图标索引＋色块分组＋文字层级＋局部量化点阵。**装饰视觉层级不等于数据层级；可见的圆点也不一定代表计数统计。**

## D｜数据／信息架构

**数据层：主对象表＋异构经历条目表＋技能评价表。**

1. **人物主表（每人一行）**：`Person ID｜姓名｜简介｜出生日期｜地址｜电话｜邮箱`。
2. **分类条目表（每条教育、经历、职业能力一行）**：`Person ID｜类别｜项目名称｜附加说明｜年份｜图标`。
3. **技能评价表（每个软件／语言一行）**：`Person ID｜技能类别｜技能名称｜原图数值（如有）｜点阵评分｜评分单位／说明`。

**信息呈现层**：主体身份／肖像 → 教育与介绍 → 实践经历与联系方式 → 专业能力与软件、语言能力。单页可按模块直接检索，不必从头读到尾。

## E｜视觉叙事架构

**视觉入口 → 人物身份 → 资历与实践 → 职业能力 → 技能评价。**

1. **入口吸引**：左上黑白人物大幅照片、竖排姓名与彩色错位剪影构成第一视觉中心；右上“hi there!”强化个性化介绍。
2. **身份建立**：右上简介写出专业背景、室内设计经验以及个人特点。
3. **资历证明**：中左的教育信息和下方培训、实习通过独立条目说明学习与实践经历。
4. **快速索引**：中右以日历、地址、电话、邮件等图标形成便于跳读的个人资料列表。
5. **能力落点**：下方专业能力图标，以及右下橙色背景的技能圆点阵列和语言百分比成为最终重点。

**叙事规律**：通过照片、字号、色块面积和空间位置建立**推荐阅读路线**，底层信息则是可独立跳读的分类档案；视觉阅读序列不等同于编年型数据结构。

## 归类理由／可迁移判断方法

- **表现类型**：视觉简历型，因其表达目的和模块构成均面向“介绍一个人及其资历”。
- **五大逻辑主类**：编目型，因异构信息被归入教育、经历、能力等类别；**技能评分子区域**可视作独立同构单元的局部表现。
- **与单一图表型的区别**：点阵图不是整张海报的唯一主干；绝大部分内容通过人物图像、列表、标题与图标呈现。
- **与层级型的区别**：标题与子项目具有信息层次，但没有一套贯穿全图的父子谱系／上下级关系。
- **与地理图型的区别**：出生地、地址只是联系方式字段，没有空间地理映射。

**一句话总结**：这是一张**编目型数据架构＋视觉简历型呈现＋局部点阵技能评分**的信息图形。
