## 核心区分

- **数据逻辑**：调用 [01-信息图形数据逻辑](../01-信息图形数据逻辑/) 判断编年型、层级型、编目型、字母表型、地理图形；一张作品按主导组织关系判断，不因出现某个局部元素就机械归类。
- **图形类型标签**：调用 [02-信息图形类型案例](../02-信息图形类型案例/) 下的 17 个类型标签；允许有主标签和辅标签，但必须说明实际承担的作用。
- **ISOTYPE**：见 [03-ISOTYPE 基础设计方法](../03-ISOTYPE基础设计方法/)；它是视觉符号与数量表达方法，**不是第 18 种类型**。
- **统计图形**：调用 [04-统计图形分析](../04-统计图形分析/) 选择合适统计图及字段、计算方式，和成品“信息图形类型”不是一回事。
- **表现风格**（平面、照片、拼贴、线描等）与**数据结构**分开记录；并非“照片风格 = 图片式信息图形”。
- **证据层次**：原始材料、计算结果、设计推断和大模型建议分别标记，未经核实的资料不得写作事实。

## 文件使用规则

1. 各阶段的 `README.md` 是操作指引；相关 `.md` 是待填写的可复用记录模板；资源目录使用 `.gitkeep` 保持空目录可见。
2. 数据集、引用素材和设计结果应附来源、许可、时间、处理步骤。大模型讨论用于辅助决策，不代替原始数据核实。
3. 每推进一个阶段，再更新本目录的阶段状态。先建立结构，**不预置未经选题确定的具体数据或成品**。
4. 本课程项目与其他学科课题无关；不把以前的作业直接当作新选题素材。
