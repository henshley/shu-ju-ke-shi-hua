# 06｜视觉编码（设计表达为主）

目标是**把第 5 阶段确定的信息关系，转译成清晰、准确、具有风格的视觉形式**，并保留可核对的数据含义。

工作内容：
- **点线面体**：点的位置、线的连接和宽度、面的面积与分区、体的装饰/空间效果；
- **统计图形**：从 [04](../../04-统计图形分析/) 选用柱图、矩阵图、Treemap、桑基图等，记录字段映射与统计计算；
- **符号方法**：ISOTYPE 的固定单位重复图标与标准化符号；查看 [03-ISOTYPE专题](../../03-ISOTYPE基础设计方法/)；
- **图像图形**：照片、插画、图标、辅助线与装饰形如何分工，哪些承载数据、哪些只作信息引导；
- **字体与版式**：标题/小标题/正文/注释字体层级、字距、行距、网格、留白、对齐、阅读路径；
- **色彩**：类别色、数量连续色阶、强调色、对比度、背景色；
- **整体风格**：平面、摄影、拼贴、线描等样式与叙事意图是否相符。

视觉编码检查：**区分编码与装饰**，凡长度、面积、数量、位置、颜色等用于表达数据，都必须有明确的量纲/范围/图例。不要为美观任意改变统计比例。

填写 [视觉编码与版式规范.md](视觉编码与版式规范.md)；源图标放 `符号图标与ISOTYPE/`，风格参考放 `色彩字体与版式参考/`。
