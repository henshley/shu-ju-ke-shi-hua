## 2. 如何核对某张图的真实规则

以 Treemap 为例：

| 需要核实的内容 | 精确入口 |
|---|---|
| 图形在不在 App 中 | [App 的 charts.js](https://github.com/rawgraphs/rawgraphs-app/blob/master/src/charts.js) |
| 英文图名/教程/简介 | [treemap/metadata.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/metadata.js) |
| 必填字段/字段类型/多字段限制 | [treemap/dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/dimensions.js) |
| 怎样分组、聚合 | [treemap/mapping.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/mapping.js) |
| 怎样计算几何位置/图形面积/图例 | [treemap/render.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/render.js) |
| 哪些布局参数可修改 | [treemap/visualOptions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/visualOptions.js) |

其他图形可按同一目录约定访问，例如 `rawgraphs-charts/src/barchart/`、`src/boxplot/`、`src/sankeydiagram/`。

## 3. 已确认的可复用机制

- App 静态注册 **32** 种图形：31 种从 Charts 包导入、1 种 Calendar Heatmap 从独立包导入；用户加载的自定义图不在这个数字内。
- 柱图、Treemap、Matrix 等源码中，可选 Size 留空可能采用**记录数量**作为尺寸/值；填入时根据映射聚合。
- Core 和 App 会验证必填字段、字段的 `number/string/date` 类型以及多字段最少值数（例如 Alluvial 的 steps 至少两个）。
- RAWGraphs 图形既包括统计意义较强的趋势/分布，也包括树图、网络图、二维几何划分等，不可把所有图都视作“简单百分比图”。
- Exporter 代码支持 `svg/png/jpg/rawgraphs`。SVG 适合后续矢量排版；`.rawgraphs` 用于项目配置的保存/恢复，而不是图片格式。

## 4. 尚未验证或需要限定的内容

1. **日历热力图**：确认静态注册和依赖包名，但本次未读取到 `@rawgraphs/rawgraphs-calendar-heatmap` 对应版本的字段定义，不能在 03 的索引中假定官方精确字段名称。
2. **每张图的所有算法细节**：已核对各图必填维度及代表性 mapping，但未对 31 张图逐个建立渲染测试。特别是 Contour、Horizon、Violin、Voronoi 等图的精确平滑/分箱/布局公式要逐项读 `render.js` 后才应固化结论。
3. **在线运行版与本次源码快照**：App `package.json` 标 `2.1.0`，官网已发布 [2.1.1](https://rawgraphs.io/news/2026-10-08-rawgraphs-2-1-1-is-out)。安装时 `^1.1.0` 等依赖声明允许一定范围内的版本升级，想要复现需要记录实际 lockfile、commit 与浏览器环境。
4. **样例图与真实课程作品之间的关系**：即使两张图外观相似，也不能断言课程作品必然使用过 RAWGraphs。我们只能说“可以借用该种统计图编码方式复刻”，除非作品或作者明确标示了工具。

## 5. 如何持续更新知识库

每增加一个统计图形的具体案例，先记录：
- 图表官方英文名及源代码目录；
- 数据示例的行粒度、列名、数据类型；
- 使用了哪些必填/可选图形变量；
- 聚合运算、几何编码、样式选项；
- 适用的统计问题与误读风险；
- 图形最终作为信息图的哪些模块，其 A–E 分析中的统计部分如何借用。

若新版本改变了维度或算法，把此前的说明标为“旧版”，注明验证日期与对应 commit；不要直接覆盖历史差异而不说明。
