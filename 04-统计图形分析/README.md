# 04-统计图形分析｜RAWGraphs 源码学习与选图知识库

> 研究对象：[RAWGraphs App](https://github.com/rawgraphs/rawgraphs-app)（`master`），并交叉核查其引用的 [RAWGraphs Charts](https://github.com/rawgraphs/rawgraphs-charts)、[RAWGraphs Core](https://github.com/rawgraphs/rawgraphs-core)。整理日期：2026-11-23。内容为源码学习笔记，不是将软件图形逐一等同于本课程信息图形类型。

## 本目录要回答的问题

1. RAWGraphs 是什么？如何把 Excel/CSV 行列表映射成统计图？
2. 每种图形至少需要哪些字段，哪些字段可选，适合比较数量、构成、分布、关系、层级还是变化？
3. 数据如何聚合与转换？什么情况下图形会误导？
4. 做完统计图后，如何增加标题、分组、注释、符号与阅读路径，成为完整的信息图形？

## 与原有目录的关系

- **01-信息图形数据逻辑**：回答信息为何按编年、层级、编目、字母表或地理逻辑组织。
- **02-信息图形类型案例**：保存用户实际收集的案例图、逐图说明与阅读叙事。
- **04-统计图形分析（本目录）**：回答用什么统计图表达数据、字段如何计算、何时适用。

三者可以交叉关联，但不是一一对应关系。例如 Treemap 统计图通常编码层级及大小；把它放进视觉海报或混合型信息图，不意味着它自动改写了整张图的基本数据架构。

## 用词与数据来源边界

- **“源码确认”**：直接来自上述 GitHub 源码的图形名、维度必填项、默认聚合或导出选项。
- **“分析建议”**：根据统计图通用原理给出的用途、误读风险、选图建议，不冒充源码原话。
- 内置图形数以 `rawgraphs-app/src/charts.js` 的静态注册表为准：**32 种，其中 31 种来自 `@rawgraphs/rawgraphs-charts`，1 种 Calendar Heatmap 来自独立依赖**。动态加载的自定义图形不计在此。
- `rawgraphs-app/package.json` 显示前端包版本 **2.1.0**；实际在线服务版本、依赖解析到的精确版本可能不同，应在复现时锁定 commit 与 lockfile。
