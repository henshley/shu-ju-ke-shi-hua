## 重要源码细节

1. **Alluvial** 的 `steps` 不仅是多列，而且 [`dimensions.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/alluvialdiagram/dimensions.js) 明确给了 `minValues: 2`。不能只填一列就叫多阶段。
2. **Bar chart** 的 `Size` 虽非必填，但 [`mapping.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/barchart/mapping.js) 规定：有尺寸字段，按配置聚合，缺省聚合为 sum；没有尺寸字段，则以组内 `v.length` 计数。使用时必须写清统计的是“记录数”还是“求和后的值”。
3. **Treemap** 的 `hierarchy` 为多列层级，`size` 可选，同样具有“不映射 size 时按记录数”的回退处理，见 [`mapping.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/treemap/mapping.js)。每个对象要算一次还是多次，必须依据实际记录含义判断。
4. **Matrix plot** 的 `x` 与 `y` 是分类交叉键，未映射 `size` 时按交叉格里的条数计数，见 [`mapping.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/matrixplot/mapping.js)。
5. **Pie chart** 的当前实现是 `arcs` 可接多列待聚合指标，见 [`mapping.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/piechart/mapping.js)；不应误写为“源码必填一列类别 + 一列数值”的通用饼图格式。如果原始 Excel 是类别/数值长表，可能需要先透视成列。
6. **Radar chart** 的 `axes` 为多列指标（源码按行遍历对象），见 [`mapping.js`](https://github.com/rawgraphs/rawgraphs-charts/blob/master/src/radarchart/mapping.js)。
7. **Calendar heatmap** 由 [`rawgraphs-app/src/charts.js`](https://github.com/rawgraphs/rawgraphs-app/blob/master/src/charts.js) 从 `@rawgraphs/rawgraphs-calendar-heatmap` 单独引入；本次无法直接读取相应版本的 `dimensions.js`，因此**未将想当然的 Date/Value 字段名冒充源码确认**。正式使用时请在 App 选中该图，查看实际必填项。
8. 表中的“统计目的”由图形惯用读法总结。例如 Voronoi 是几何空间分区工具，并不自动代表地理地图；Arc 是连线关系而不自动代表时间流向；Horizon graph 的亮度/层级需要查图例而非凭颜色猜数量。

## 数据维度究竟是什么？

`dimensions.js` 的字段定义不是“Excel 有几行几列”的限制，而是“至少要有几类意义不同的列”。表可以有几万行；关键是每行含义统一、必填槽位对应正确类型。

- `x` / `y`：两个坐标字段；对散点来说每行是一个点。
- `hierarchy`：一组有顺序的层级列，例如“省 / 市 / 区”，各行代表末级对象。
- `source` / `target`：一行是一条边，代表谁连到谁。
- `steps`：一行是同一对象在多阶段的类别状态。
- `size`：权重/数量；同名字段在不同图形下可能具有不同聚合默认值。
- `series`：把一张图拆成不同系列或面板的附加分类。
- `color`：独立的类别或数值编码，**不是把字段值直接当作 RGB 代码**。

## 下一步怎么学习

从 [样例数据目录](https://github.com/rawgraphs/rawgraphs-app/tree/master/public/sample-datasets) 逐类选一份 TSV/CSV，观察它的表头，再对照本表和对应的 `dimensions.js` / `mapping.js`。建议先做 Bar → Matrix → Treemap → Alluvial → Sankey → Boxplot → Bubble，理解行记录、聚合、层级和关系的差别后，再研究比较抽象的几何图。
