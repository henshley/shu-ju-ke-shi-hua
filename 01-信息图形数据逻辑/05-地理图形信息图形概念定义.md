# 地理图形信息图形概念定义

## A 基本的数据逻辑

空间位置、方位、邻接、路线或覆盖范围是主要关系。对象可对应点、线、区域，也可对应沿地点变化的指标。[帝都地图](../02-信息图形类型案例/README.md#da-06-帝都地图) 的地点虽然来自虚构世界，街区相对位置和道路连接仍决定了它的读法。

**判断方法**　调换两个地点或挪动一条线，观察空间结论是否会变。课件也收录了 [世界山脉与河流比较图](../02-信息图形类型案例/README.md#da-08-世界山脉与河流比较)。它属于地理主题，但主图可以主要按高度和长度来读。分析此类作品时分别记录题材和布局中的主关系。

## B 统计图形与计算方式

| 表达任务 | 图形与统计方式 |
| --- | --- |
| 找地点、街区和路径 | 用定位地图或线路地图。先将地点和路线对应到底图，按图例区分不同设施、道路与区域。 |
| 看各区指标怎样分布 | 用分级设色地图。比较风险或占比时可按人口、面积等适当分母标准化，再按明示的阈值分级。 |
| 看各地总量或流向 | 用比例符号地图或流向图。制图时让符号面积或线宽对应明确的量，并在图例中交代单位。 |
| 看地貌和河道变化 | 用等高线、高程剖面或多期河道叠图。两期比较使用统一底图与空间范围。 |

[密西西比河历史河道图](../02-信息图形类型案例/README.md#da-07-密西西比河历史河道) 可沿底图读取不同河道范围。原图的填色用于辨认图例分组，比较面积前要确认比例尺和面积计算口径。

## C 视觉编码

点定位地点，线表达河道、路线和边界，面表达地块和覆盖范围。色相可区分地物或历史河道，顺序色阶可表示量级。符号配合地名和图例解释地点类型。立体高程应与可读的高度基准对应，优先保证地图的方位与地点标记清楚。整体范围与局部细节可用主图和插图衔接。

## D 数据与信息架构

最小记录包括 `地点或区域 ID、名称、空间几何、属性或指标`。定量专题可补充 `日期、单位、分母、来源`。历史地图还需记录时期、底图范围和图例类别。信息层可包括底图、专题层、地名标注、图例与补充图，数据有尺度时附比例尺和方位说明。

## E 视觉叙事架构

先让读者认清地图的范围，再由图例定位主要区域、路径和重点标注。河道案例可以从现有底图进入，沿河谷辨认多条历史河道的叠合，并通过图例理解它们所处的组别。[帝都地图](../02-信息图形类型案例/README.md#da-06-帝都地图) 则支持从中心城区向外按道路寻找相邻街区。
