# 编年型信息图形概念定义

## A 基本的数据逻辑

以一条有方向的序列组织事件、阶段或状态变化。核心关系是「第几步、谁先谁后、哪些项目属于同一阶段」。课件第 3 页概括为单向、不可逆、顺序排列，数据维度以一条主要序列为主。这里的不可逆指先后关系由记录或规则确定。排版可以从下往上，也可以折返，读取方向可以改变，原本的先后关系仍须成立。并行事件可共用一个顺序位置，或并排放在各自的轨道上。

**判断方法**　交换两个节点以后，如果读者会误解事情的经过，说明顺序承担了结构功能。如果交换只影响条目好不好找，应继续检查排序是否只是索引。课件的 Gear Timeline 用连续曲线串起阶段，能沿路径辨认前后关系。

## B 统计图形与计算方式

| 需要回答的问题 | 图形与处理方式 |
| --- | --- |
| 发生了哪些事、顺序如何 | 用事件节点或分段轴。按顺序键排序，节点和说明一一对应。仅知道先后关系时，可用等距排列。 |
| 相隔多久、持续了多久 | 用等比例轴和区间条。位置由实际刻度确定，区间长度为结束值减开始值。 |
| 数值怎样随序列变化 | 用按期柱形图比较各期合计，用折线图显示同口径数值的变化。增减量为本期减上期，百分比增减还需同口径的非零基期。 |

包豪斯案例 显示年份节点和建筑注释。由图可读出先后，读取精确间隔前需要确认刻度。原图中未标单位的节点大小或图像面积按图文布局解读。

## C 视觉编码

点定位事件。线串联相邻节点，折返处保留连续性和方向提示。面承载阶段分区或已定义的区间。色彩区分阶段、支线或重点，图例维持一致。建筑轮廓等符号帮助识别事件对象。需精确比较数值时，优先让共用标尺上的位置或长度承担读数，立体效果用于说明形态时应保留可读的二维刻度。

## D 数据与信息架构

最小记录可以是 `事件 ID、顺序键、显示标签、主体、事件说明、来源`。区间事件补充起止值，并行序列补充轨道，同期事件共用顺序键且各有事件 ID。页面用一条主轴形成总览，按阶段组织节点，详情和图像从节点展开。

## E 视觉叙事架构

让读者先找到开端和读取方向，再沿主轴认识阶段的变化，最后通过注释查看里程碑为何重要。内容折返或环绕时，每次转换方向都要保有接续线索。案例既有 单人经历的曲线阶段，也有 报刊跨页中的连续折返。
